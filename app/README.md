# Kris V1.3.0

本地优先的 Kris 个人教练 PWA。V1.2 使用“编辑型训练日志”视觉方向：米白底、黑色主状态、荧光绿行动区，减少卡片和阴影，优先显示今天要做什么。它读取 Obsidian 派生层的 `coach_snapshot.json`、体测记录、每日健康汇总和训练负荷汇总，只展示数据，不上传健康信息，也不会自动刷新 SyncHealth。

V1.3 增加训练智能视图：14/42 日负荷切换、7/42 指数负荷、同器械动作进阶状态与最近实绩。负荷只用于个人趋势语境，不等于疲劳或伤病预测。

## 启动

在项目根目录运行：

```bash
python3 app/server.py
```

然后打开 <http://127.0.0.1:8765>。

如果要让同一 Wi-Fi 下的 iPhone 访问，在 Mac 上运行：

```bash
KRIS_HOST=0.0.0.0 python3 app/server.py
```

然后在 iPhone Safari 打开 `http://Mac的局域网IP:8765`，即可通过“添加到主屏幕”安装为 PWA。V1 没有登录、TLS 或公网反向代理，不要把这个端口直接暴露到互联网。

SyncHealth 点击 `syncnow` 并完成本地刷新后，在页面右上角点击 `↻` 重新读取快照。V1 不做定时轮询。

## 设计边界

- PWA 可以展示现有派生数据，但不能绕过 iOS 权限直接读取 HealthKit。
- PWA 仅作为只读回退；当前主要执行入口是仓库 `native/` 中的原生 iPhone 与 Apple Watch App。
- 页面中的准备度是个人决策分，不是医疗评分；体重、体脂和营养缺口保留数据质量提示。
