# HealthKit 导入与恢复口径

## 用户看到的状态

- `自动更新已开启`：至少有一项可用样本，HealthKit observer 已启用；App 启动或回到前台时会用 anchored query 自动补齐。
- `未读取到样本`：查询本身成功，但 42 天内没有返回任何可读样本；提示检查系统权限。
- `导入失败`：查询或构建能力失败；按错误分类提示检查权限、重新安装正确签名版本或稍后重试。
- 单项失败不清空其他指标；明细按指标显示本次新样本数和失败原因。

## 恢复策略

1. 正常启动只使用 anchored query 获取增量。
2. 某指标从未成功读到样本时，继续保留该指标的 42 天有界回填资格，避免用户后来授权却被旧锚点卡住。
3. 用户可显式执行“重新回填最近 42 天”；这会替换该指标尚未上传的旧队列批次，不删除手机本地健康缓存。
4. 上传每批最多 2,000 个样本，低于 companion 的 5MB 请求上限；升级时自动把旧大批次规范化。
5. Mac 端按 `batch_id` 幂等接收，样本按 HealthKit UUID 去重。

## 睡眠口径

- HealthKit 睡眠阶段先按不超过 90 分钟的间隔聚合成睡眠会话，再判断主睡眠或午睡。
- 10:00–18:00 开始且少于 4 小时的同日短会话才判为午睡；长时间或跨夜会话属于主睡眠。
- 主睡眠按结束日期的前一天作为 `night`，由次日健康汇总读取。
- 同一状态的重复或跨来源重叠区间按时间并集计时，不直接求和。
- 修复前数据库备份保留在 `~/.synchealth/backups/health-before-sleep-session-v2-20260901.db`。
